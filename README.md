# labwork-Lifecycle

### Виконавець: Данчевський Владислав Олегович

Тема проекту: **Система контролю прострочених бібліотечних видань**.

Опис: Програма призначена для контролю видачі бібліотечних видань та відстеження книг, термін повернення яких був порушений. Система дозволяє бібліотекарю зберігати інформацію про книги, читачів, видачу видань та автоматично визначати прострочені повернення.

Обрані технології:

  1. Laravel Framework (backend)
  2. React Framework (frontend)
  3. MySQL (storage)
